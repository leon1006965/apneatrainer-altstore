# ApneaTrainer AltStore Source

Add this source to AltStore to install ApneaTrainer.

## Add Source

Open this URL on your iOS device with AltStore installed:

```
altstore://source?url=https://raw.githubusercontent.com/leon1006965/apneatrainer-altstore/main/apps.json
```

Or manually add this URL in AltStore's Sources tab:

```
https://raw.githubusercontent.com/leon1006965/apneatrainer-altstore/main/apps.json
```

## What is ApneaTrainer?

Free apnea breath training for iOS. O2 tables, CO2 tables, custom tables and more.

- iOS 15.0+
- Open source: [github.com/leon1006965/ApneaTrainer](https://github.com/leon1006965/ApneaTrainer)
